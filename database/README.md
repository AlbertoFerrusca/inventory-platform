# Database
## Purpose
This directory contains PostgreSQL database assets required to support the inventory management platform.
## Components
### DDL
Database schema definitions including:
- Tables
- Primary Keys
- Foreign Keys
- Indexes
- Constraints
### Views
Database views used for reporting, analytics, and operational queries.
### Procedures
Stored procedures used for business processing, inventory calculations, batch operations, and data maintenance.
### Functions
Reusable database functions supporting platform business logic.
### Migrations
Schema evolution scripts used to deploy and version database changes.
## Related Components
The database layer integrates with:
- Microservices
- Python Processing Jobs
- Kafka Consumers
- Kafka Producers
- Batch Processes
- Shell Scripts
## Inventory Processing
  The database stores inventory information that can be managed and distributed by:
- State
- Region
- Branch

Inventory updates are received through event-driven processes and persisted for operational and analytical purposes.

## Observations
- The database serves as the system of record for inventory, transactional, and operational data.
- Inventory information can be managed and distributed by state, region, and branch.
- Database entities are integrated with Kafka through Change Data Capture (CDC) mechanisms for event publication and downstream processing.
- The database supports both transactional workloads and batch-oriented processing.
- Stored procedures, functions, views, and scheduled processes are used to execute business rules and inventory-related operations.
- Data generated by operational processes may be consumed by microservices, Python services, and Kafka integrations.
- Database assets are version-controlled to ensure traceability, consistency, and deployment reproducibility across environments.

## Architecture Role
PostgreSQL acts as the primary persistence layer for the platform, supporting inventory management, business transactions, reporting, batch processing, and CDC-based event integration with Kafka.
