### Python Background Workers

The platform includes a set of Python-based background workers that act as RabbitMQ consumers.
These workers are responsible for processing asynchronous business events generated by the microservices and executing database operations through stored procedures and database functions.
Current workers include:

- `eventos.py`
- `ordenesii.py`
- `payment.py`
 
### Responsibilities

- Consume messages from RabbitMQ queues.
- Process business events asynchronously.
- Execute stored procedures and database functions.
- Persist and update business data in relational databases.
- Decouple long-running processes from synchronous service requests.
 
### Scalability

The workers are designed to run as independent background processes.
Depending on system demand, multiple worker instances can be launched to increase message processing throughput and handle higher event volumes.

### Deployment

Python workers are executed in the background through shell scripts and can be started, stopped, and scaled independently from the Spring Boot microservices.

### Technology Stack

- Python
- RabbitMQ
- SQL Server / Relational Database
- Shell Scripting
- Stored Procedures
